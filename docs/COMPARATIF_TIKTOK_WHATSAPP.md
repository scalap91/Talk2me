## 3. Organisation & Proportions : ce qui fait tenir TikTok et WhatsApp

### TikTok
- **Navigation hiérarchique** : 4 onglets principaux (Accueil, Découvrir, Création, Boîte de réception, Profil)
- **Densité** : Feed infini vertical (scroll), pas de sous-menus profonds
- **Regroupements** : Contenu par algorithmes (FYP), pas par catégories explicites
- **Proportions** : 80% consommation / 20% création

### WhatsApp
- **Navigation hiérarchique** : 3 onglets (Chats, Appels, Statut) + paramètres
- **Densité** : Liste verticale de conversations, pas de scroll infini
- **Regroupements** : Par contact/groupe, pas de catégories
- **Proportions** : 90% messagerie / 10% paramètres

### Talk2Me : où c'est trop maigre
- **Navigation** : Trop de sections au même niveau (Accueil, Découvrir, Hub, Appels, Cards, Profil, Amis, Eat, Drive, Shop, Wallet, Music, Composer, Stories, Admin, Auth) → **16 entrées** vs 4-5 pour TikTok/WhatsApp
- **Densité** : Pas de hiérarchie (tout est "page principale")
- **Regroupements** : Absence de catégories (ex: "Divertissement" regrouperait Music, Stories, Cards)
- **Proportions** : Trop de fonctionnalités "utilitaires" (Eat, Drive, Wallet) sans masse critique de contenu social

### Recommandations structurelles
1. **Fusionner** : Eat + Drive + Shop → "Services" (sous-menu)
2. **Regrouper** : Music + Stories + Cards → "Création/Divertissement"
3. **Hiérarchiser** : Accueil (feed) + Découvrir + Messagerie + Profil = 4 onglets principaux
4. **Déporter** : Admin, Wallet, Paramètres → menu latéral ou paramètres
